***Problem Statement***

Microsoft launches a viral public API: `aka.ms/hellomicrosoft`.

Build and improve the system to support the following:

- Users sign in using their Microsoft account
- Clicking "Say Hello" increments a single global counter
- Every multiple of 10,000 rewards the triggering user
- Only one user can win for each reward milestone
- The system must remain correct under heavy concurrent traffic
- Review the provided implementation, identify flaws, and fix them
